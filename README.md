# Pomodoro

A minimal pomodoro timer that lives in the macOS menu bar.

- **Minutes + seconds ring** — the menu bar shows the minutes left and a ring of 12 dots
  that starts each minute full and empties clockwise, one dot every 5 seconds.
- **Fixed topic** — type what you're working on and press Start; the topic stays pinned
  across sessions until you clear it with ×.
- **Session log** — every finished focus session is logged with its topic. The popover
  shows today's sessions and total time; *Copy log* copies them tab-separated for a timesheet.
- **Reminders** — a notification and chime when focus or break time is up, scheduled with
  the system so it arrives on time even if the app is in the background.
- **Rocket launch** — a minimal line-art rocket flies across the screen when a focus
  session ends.
- **Focus glow** — a soft, slowly pulsing glow along the bottom edge of every screen while
  focus time runs (steady and dim while paused).
- Focus lengths of 10–50 min, breaks of 5/10/15 min or a 1 h lunch, and *Open at login*.

## Requirements

- macOS 14 or later
- Xcode Command Line Tools (`xcode-select --install`) — the full Xcode is not needed

## Build and run

```bash
./build.sh            # builds build/Pomodoro.app
./build.sh install    # also copies it to /Applications and (re)starts it
```

Previews without waiting for a session to end:

```bash
open -a Pomodoro --args --rocket       # rocket animation
open -a Pomodoro --args --focus-edge   # focus glow for 15 s
```

The app icon is generated by `tools/make-icon.swift`; delete `Resources/AppIcon.icns`
and rebuild to regenerate it.

## Project layout

| File | What it does |
|---|---|
| `Sources/PomodoroApp.swift` | App entry, menu bar item, notification setup |
| `Sources/PomodoroTimer.swift` | Timer state, phases, topic, session log, notifications |
| `Sources/ContentView.swift` | The popover UI |
| `Sources/SecondDots.swift` | The 12-dot seconds ring (menu bar and popover) |
| `Sources/RocketLaunch.swift` | Rocket overlay animation |
| `Sources/FocusEdge.swift` | Bottom-edge focus glow |
| `tools/make-icon.swift` | Generates `Resources/AppIcon.icns` |
| `build.sh` | Compiles with `swiftc` and assembles the `.app` bundle |

The app is ad-hoc signed for local use. Settings and the log are stored in the app's
user defaults (`local.pomodoro.timer`).
